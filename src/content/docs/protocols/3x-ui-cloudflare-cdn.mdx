VLESS + WS + Cloudflare CDN 节点原理是：将代理流量伪装成普通的 HTTPS 请求，经由 Cloudflare (CF) CDN 中转至服务器。即使服务器真实 IP 被封锁，只要 CF 节点仍可访问，你的节点就始终在线。

本文基于较新版本 3x-ui 面板（3.7.0）整理，介绍如何配置 VLESS + WebSocket + Cloudflare CDN 节点——它不追求极致速度，而是作为 Reality 节点被封锁时的备用保命通道。

## 前置准备：安装 3x-ui 面板

如果你还没有安装 3x-ui 面板，请先参考系列第一篇《[3x-ui 面板保姆级教程（一）：准备工作、域名端口规划、面板安装教程](/protocols/3x-ui-guide-1/)》完成安装。本文承接系列第二篇的 Reality 节点，继续为你的面板补充一条 CDN 保命通道。

## Cloudflare 后台配置要点

### 1. DNS 设置

将域名[托管到 Cloudflare](https://www.zoio.net/2026/01/cloudflare.html)，添加一条 A 记录指向你的 VPS IP，必须开启代理（即点亮小黄云/Proxied）。

![Cloudflare 域名解析](https://img.zoio.net/?url=//blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEiNRp7GnDnH758J0yqgmV99Yjdpf1-vn_v6iM-Fb4NnArq6IrlWol99aWAYUIABc3-eLvCplIMaZK2cYpXoCox88Dn1FbmY0rQP4-55wQZidAcjexbP4bfOVneSg86ngwJn1TaFSRimOyPoGJY-6VSdUpWEO2DZZC09vZX6HbeDdPK0CJu1ex98KkS7jYc/s1600/3x-ui-1-0.webp)

在 Cloudflare 后台进入你的域名「 SSL/TLS 」-「 概述 」将 SSL/TLS 设置为 **完全（严格）**

### 3. 创建 Origin CA 证书

在 Cloudflare 后台可以免费申请有效期长达 15年 的源服务器证书（Origin Certificate）。这样就不需要配置复杂的 acme.sh 自动续期，非常适合套了 CDN 的节点。

在 Cloudflare 后台进入你的域名「 SSL/TLS 」-「 源服务器 」-「 Origin 证书 」点击「 创建证书 」

### 1. 添加入站 - 基础配置

- **备注** 随便填，我是美国纽约的 VPS，例如 `🇺🇸 NY-WS` （[国旗 Emoji](https://www.zoio.net/2026/01/country-codes.html) ）
- **协议** 选择 `vless`
- **分享地址策略** 选择 自定义
- **自定义分享地址** 填写 开启了 CDN 的域名，例如：`ny-cdn.zoio.sryze.cc`
- **端口** 填写 CF 支持的端口，例如： `2053`
- **其他** 保持默认

### 4. 添加入站 - 安全

- **安全** 选择 `TLS`
- **SNI** 输入 `ny-cdn.zoio.sryze.cc` 必须与上一步的**主机**域名保持完全一致
- **uTLS** 保持默认 `chrome`, 模拟真实 Chrome 浏览器的特征
- **ALPN** 只保留一个 `http/1.1`
- **拒绝未知 SNI** 建议开启，防扫描探测
- **会话恢复** 建议开启，允许客户端在短暂断开后，直接复用上一次的 TLS 密钥进行快速连接，不需要重新进行繁琐的 TLS 握手。
- **数字证书 1** 选择 文件内容
- **公钥** 粘贴 Origin CA 证书：源证书
- **私钥** 粘贴 Origin CA 证书：私钥
- **其他** 保持默认
