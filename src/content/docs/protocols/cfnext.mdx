CFNext：最新 Cloudflare Workers 免费节点项目，在 Cloudflare Workers / Pages 的代理订阅管理面板中部署，单文件同时实现 VLESS / Trojan / XHTTP 多协议代理与图形化配置：/UUID（或自定义路径）进入面板，/sub输出订阅；内置节点优选器、节点数量控制、轮询下发、ECH 加密、落地与出站代理及地区 / 运营商 / IP 版本多维筛选，部署即用，绑定 KV 后改完成即生效。

**CFNext 项目地址**：[https://github.com/netrair/netra-panel](https://github.com/PAICNI/CFNext)

**CFNext 主要功能**

- 运行于 Cloudflare Workers — 无需 VPS、无需 Docker，省去维护和重启服务器的繁琐。
- 多协议支持：VLESS / Trojan / XHTTP 三协议独立开关，可同时启用；Trojan 密码留空默认使用 UUID。
- 订阅模式：关闭（默认）/ 自定义订阅（支持汇聚）/ 随机优选模式（官方接口）三种模式切换
- 节点数量控制：下拉开关 + 数量输入，开启后精确控制下发节点总数（1-1000）
- 轮询机制：默认开启：Clash 上限 300 / V2rayN 上限 800，更新订阅覆盖旧节点；关闭后忽略限制一次下发全部
- 优选器：内置微测网 IPv4/IPv6、优选 IP 列表、HostMonit 优选、微测优选域名 + 自定义数据源 URL；在线 TCP 测速后「加入优选」随订阅下发
- 自定义订阅：内置 6 条在线源（bestcf 地区源，可增删），支持域名 / 优选 API / IP 逐行汇聚；可切换「仅自定义节点」——关闭后只下发输入框内内容
- 地区与筛选：地区选择（全部 / 香港 / 台湾 / 美国 / 新加坡 / 日本 / 韩国 / 德国）+ IP 版本（IPv4 / IPv6）+ 运营商（移动 / 联通 / 电信）组合筛选
- 落地与出站：反代 / 落地 IP（留空使用内置 VLESS 中继 + 地区反代兜底；填写后启用透明代理）+ 出站代理（SOCKS5 / HTTP，user:pass@host:port）+ 出站模式选择
- ECH 加密：自定义 ECH 域名 / ECH DNS（DoH），开启后自动进入仅 TLS 节点模式
- 多客户端：Clash / Sing-box / Surge / Loon / Quantumult X / V2ray / Shadowrocket / Nekoray / Stash，按 UA 自动识别（URL 追加 ?format= 可强制指定）
- ...

## 部署教程

### 把域名托管到 Cloudflare

虽然 Cloudflare 提供了默认域名，但由于众所周知的原因无法在大陆直连。建议绑定自己的域名并开启 CDN。你可以使用[免费域名](https://www.zoio.net/2026/02/free-indevs-in-domain.html)，并参考教程将[域名托管到 Cloudflare](https://www.zoio.net/2026/01/cloudflare.html)。

### 添加自定义域

Cloudflare 官方分配给 Workers 的默认二级域名（以 `*.workers.dev` 结尾）在中国大陆已被全面阻断,下发的节点 SNI 取自访问域名，会导致客户端真连接延时全部 -1。为了正常使用，建议绑定一个自定义域名。

在 Worker 设置中选择「域和路由」标签页，点击「添加自定义域」。

![设置自定义域](https://img.zoio.net/?url=//blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEgUdSjjR2y3lb79W2Z2eJXHay_jZ2rNkUjxXYj_Hzec1nUmJoSptHhApMj_OunemNpKDUR1psB7btNHNULzjLkZ4ryTPbyyJIk_lRbaGKSz4GAjSYY35_2NmMi6zCRQvlYi_Jft0-eg6l_4ZxuJ5ZdC41vdQNyU7U0RGNlziuUjke5vAIo14MujuS8xC04/s1600/netra-panel-13.webp)

输入你托管在 Cloudflare 上的子域名，然后点击「添加域」。

![设置自定义域](https://img.zoio.net/?url=//blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhnyON3VKFSMZDJ5UV4xPuhqgnRFp8_9Cry1bdFCi5cqGhb9Nomlgqvu81oFwWZY3M7ZN6jnrgHShqwJaN5EcY2IzDTm5bckui3mmSOVRwAFPsW9BtWAjBnee8mjtf51L5nbG8a4DEMKW18Cn3Z7L0gKab7KW_wbdalS8A6ZGrNfjWX7Dxmd11o3jn2kPI/s1600/cfnext-5.webp)
