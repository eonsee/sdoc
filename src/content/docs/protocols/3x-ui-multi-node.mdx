好在 3x-ui 原生引入了强大的 **多节点支持**（Multi-node management / 星型拓扑集中管理）。通过主面板（Master）利用内部 API / 远程通信凭证，你可以实现在一个面板里统一添加、修改、监控多台子节点 VPS 的入站和客户端。

---

## 整体架构说明

多节点管理采用标准的 Master-Worker（主从）星型拓扑结构：

- **主面板**（Master）：作为你的中央控制台。你所有的用户、订阅、全局设置都在这里维护，它通过 API 统一指挥各个子节点。
- **子节点**（Worker）：分布在不同地区、只负责运行 Xray 核心转发流量的 VPS。它们不需要你频繁单独登录，所有配置由主面板自动下发。

---

## 准备工作

在开始配置前，请确保满足以下条件：

- **两台或多台 VPS**：其中一台作为主面板（Master），其余作为子节点（Worker），可分布在不同地区，均已完成基础的 3x-ui 安装。
- **面板版本**：确保两台 VPS 上已安装 3x-ui 并升级到最新版本。

---

## 配置受控节点（Worker VPS）

首先需要登录你的子节点 VPS，为 Master 面板的远程调用开放 API 访问权限。

登录子节点 VPS 的 3x-ui 管理面板。进入「 面板设置 」-「 安全设定 」-「 API 令牌 」新建令牌。

## 在主面板（Master）中添加远程节点

接下来切换到你的**主控服务器面板**，将子节点添加进来。

在左侧菜单栏中找到「 节点 」点击「 添加节点 」。

![添加节点](/images/protocols/3x-ui-6-2-c585f29a00.jpg)

添加节点

在「 添加节点 」（Add Node）表单中填写以下信息：

- **名称/备注** 自定义
- **协议** 保持默认 `https`
- **地址** 子节点 VPS 的 IP 地址或域名
- **端口** 子节点 3x-ui 面板的访问端口
- **基础路径** 子节点 3x-ui 面板的访问路径
- **API 令牌** 填入子节点创建的 API 令牌

点击保存测试连接。如果显示连接成功，说明主面板已经成功通过 API 牵手了这台子节点。

![添加节点 - 连接测试成功](/images/protocols/3x-ui-6-3-a93d1e403f.jpg)

添加节点 - 连接测试成功

添加成功后，可在主面板查看子节点的状态、CPU、内存、Xray 版本等信息。

![子节点状态与资源信息](/images/protocols/3x-ui-6-4-792680733f.jpg)

子节点状态与资源信息

## 通过主面板在子节点上添加入站

节点连通后，你就可以像管理本地节点一样管理远程子节点了：

![远程子节点列表](/images/protocols/3x-ui-6-5-5e29cf6de6.jpg)

远程子节点列表

在主面板 **添加入站** 时，面板会让你选择该入站生效的目标节点（你可以选择部署在主节点，也可以选部署到刚才添加的“纽约”上）。

![添加入站 - 选择目标节点](/images/protocols/3x-ui-6-6-5051532bf2.jpg)

添加入站 - 选择目标节点

多节点模式下，客户端的实时在线状态和流量数据会通过 API 定期回传给 Master 面板。如果发现延迟，可以检查两台 VPS 的系统时间是否同步（建议使用 ntp 或 chrony 校准时间，时间不同步会导致 API 认证失败）。
