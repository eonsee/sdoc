### 4. 添加入站 - 安全

- **安全** 选择 `Reality`
- **uTLS** 保持默认 `chrome`
- **目标** 查找目标，选择 `www.cloudflare.com:443`
- **SNI** 只保留一个 `www.cloudflare.com`
- **最小客户端版本** 输入 `1.0.0`

最小客户端版本：留空不等于不限制：Xray-core 会改用所运行内核版本的内置最低值（当前版本为 26.3.27），拒绝自报版本更低的客户端——包括 Mihomo、sing-box 等第三方内核。填 1.0.0 可放行它们，代价是允许过时的 TLS 指纹。
