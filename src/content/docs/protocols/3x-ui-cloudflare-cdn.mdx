本文基于较新版本 3x-ui 面板（3.7.0）整理，介绍如何配置 VLESS + WebSocket + Cloudflare CDN 节点——它不追求极致速度，而是作为 Reality 节点被封锁时的备用保命通道。

## 前置准备：安装 3x-ui 面板

如果你还没有安装 3x-ui 面板，请先参考系列第一篇《[3x-ui 面板保姆级教程（一）：准备工作、域名端口规划、面板安装教程](/protocols/3x-ui-guide-1/)》完成安装。本文承接系列第二篇的 Reality 节点，继续为你的面板补充一条 CDN 保命通道。

## Cloudflare 后台配置要点

### 1. DNS 设置

将域名[托管到 Cloudflare](https://www.zoio.net/2026/01/cloudflare.html)，添加一条 A 记录指向你的 VPS IP，必须开启代理（即点亮小黄云/Proxied）。

![Cloudflare 域名解析](/images/protocols/3x-ui-1-0-5e9e502963.jpg)

Cloudflare 域名解析

---

### 2. SSL/TLS 设置

在 Cloudflare 后台进入你的域名「 SSL/TLS 」-「 概述 」将 SSL/TLS 设置为 **完全（严格）**

![Cloudflare SSL/TLS 设置](/images/protocols/3x-ui-3-1-0c8a66809f.jpg)

Cloudflare SSL/TLS 设置

---

### 3. 创建 Origin CA 证书

在 Cloudflare 后台可以免费申请有效期长达 15年 的源服务器证书（Origin Certificate）。这样就不需要配置复杂的 acme.sh 自动续期，非常适合套了 CDN 的节点。

在 Cloudflare 后台进入你的域名「 SSL/TLS 」-「 源服务器 」-「 Origin 证书 」点击「 创建证书 」

![Cloudflare 创建 Origin CA 证书](/images/protocols/3x-ui-3-2-4bdcdac285.jpg)

Cloudflare 创建 Origin CA 证书

点击「 创建 」。

![Cloudflare 创建 Origin CA 证书](/images/protocols/3x-ui-3-3-2ac01651a7.jpg)

Cloudflare 创建 Origin CA 证书

复制并保存 源证书 和 私钥 。

![Cloudflare 创建 Origin CA 证书](/images/protocols/3x-ui-3-4-e5f38df674.jpg)

Cloudflare 创建 Origin CA 证书

## 配置 VLESS + WS + Cloudflare CDN 节点 - 添加入站

登录 3x-ui 面板，在「 入站 」-「 添加入站 」。

![3x-ui 添加入站](/images/protocols/3x-ui-3-5-921c52b4b8.jpg)

3x-ui 添加入站

---

### 1. 添加入站 - 基础配置

- **备注** 随便填，我是美国纽约的 VPS，例如 `🇺🇸 NY-WS` （[国旗 Emoji](https://www.zoio.net/2026/01/country-codes.html) ）
- **协议** 选择 `vless`
- **分享地址策略** 选择 自定义
- **自定义分享地址** 填写 开启了 CDN 的域名，例如：`ny-cdn.zoio.sryze.cc`
- **端口** 填写 CF 支持的端口，例如： `2053`
- **其他** 保持默认

![3x-ui WS + Cloudflare CDN 节点 添加入站 - 基础配置](/images/protocols/3x-ui-3-6-9e7b7a8c82.jpg)

3x-ui WS + Cloudflare CDN 节点 添加入站 - 基础配置

---

### 2. 添加入站 - 协议

- **协议** 协议这里保持默认，无需配置

![3x-ui WS + Cloudflare CDN 节点 添加入站 - 协议](/images/protocols/3x-ui-3-7-857050df75.jpg)

3x-ui WS + Cloudflare CDN 节点 添加入站 - 协议

---

### 3. 添加入站 - 传输

- **传输** 保持默认 `WebSocket`
- **主机** 填写 开启了 CDN 的域名，例如：`ny-cdn.zoio.sryze.cc`
- **路径** 自定义，配置一个复杂的路径，例如：`/zoio-net`
- **其他** 保持默认

![3x-ui WS + Cloudflare CDN 节点 添加入站 - 传输](/images/protocols/3x-ui-3-8-1dba94adb7.jpg)

3x-ui WS + Cloudflare CDN 节点 添加入站 - 传输

---

### 4. 添加入站 - 安全

- **安全** 选择 `TLS`
- **SNI** 输入 `ny-cdn.zoio.sryze.cc` 必须与上一步的**主机**域名保持完全一致
- **uTLS** 保持默认 `chrome`, 模拟真实 Chrome 浏览器的特征
- **ALPN** 只保留一个 `http/1.1`
- **拒绝未知 SNI** 建议开启，防扫描探测
- **会话恢复** 建议开启，允许客户端在短暂断开后，直接复用上一次的 TLS 密钥进行快速连接，不需要重新进行繁琐的 TLS 握手。
- **数字证书 1** 选择 文件内容
- **公钥** 粘贴 Origin CA 证书：源证书
- **私钥** 粘贴 Origin CA 证书：私钥
- **其他** 保持默认

![3x-ui WS + Cloudflare 节点 添加入站 - 安全](/images/protocols/3x-ui-3-9-a8101fba5e.jpg)

![3x-ui WS + Cloudflare 节点 添加入站 - 安全](/images/protocols/3x-ui-3-10-d59d2fb0f0.jpg)

3x-ui WS + Cloudflare CDN 节点 添加入站 - 安全

### 5. 添加入站 - 嗅探

- **启用** 点击启用
- **勾选** 选择 `HTTP、TLS、QUIC`
- **仅路由** 点击启用
