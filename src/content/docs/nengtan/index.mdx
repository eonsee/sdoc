这套教程讲的不是“若依怎么用”，而是**怎么用若依把一套能碳管理系统真正落地**：从业务边界、总体架构、技术选型，到现场仪表怎么接线、数据怎么采上来，再到若依里的模块、数据库、采集服务和部署验收。

它面向会写 Java、但没做过工业物联网项目的开发者。硬件部分从零讲起，不需要电气背景，但也不会只停留在“买个电表”这种程度——读完你应该能和电工、仪表厂商、施工队正常对话，并能自己写出可施工的点位表。

<Aside type="note" title="教程假设的场景">
  一家中型制造工厂：1 个园区总表、4 个车间、约 20 个计量点，能源介质包括电、水、天然气、蒸汽和压缩空气。系统需要做实时监控、分项能耗、定额考核、碳核算和报表。你可以按比例放大或缩小，方法不变。
</Aside>

## 你会得到什么

- 一套**能落地的总体设计**：功能架构、数据流、部署架构、与若依模块的对应关系。
- 一份**明确的技术栈**：后端、前端、数据库、时序库、消息队列、物联网接入、部署运维，以及每个选择的理由和替代方案。
- 一份**零基础也能看懂的硬件指南**：电表与互感器接线、水气汽计量、RS-485 与 Modbus、网关与 DTU、点位表、施工调试和故障排查。
- 一条**可执行的实现路径**：若依工程改造、核心表结构、采集服务代码、碳核算服务、前端页面和上线检查清单。

## 先记住这几个词

| 术语 | 一句话解释 |
| --- | --- |
| 能源介质 | 被计量和管理的能源种类，如电、水、天然气、蒸汽、压缩空气 |
| 计量点 | 一个独立的计量位置，例如“1 号车间总进线”。它对应一块表或一组采集通道 |
| 点位 | 计量点上的一个具体数据项，例如 A 相电压、有功功率、累计电量 |
| 采集网关 | 把现场仪表的协议转成平台能懂的数据，并负责上传的设备 |
| 边缘计算 | 在网关上先做过滤、报警、缓存，不必所有原始数据都上云 |
| 活动数据 | 碳核算里“用了多少”，例如消耗了多少 kWh 电、多少立方米天然气 |
| 排放因子 | 每单位活动数据对应的碳排放量，例如每 MWh 电对应多少吨 CO₂ |
| CO₂e | 二氧化碳当量，把不同温室气体按全球变暖潜势折算成 CO₂ 的统一单位 |
| 范围一 / 二 / 三 | 直接排放 / 外购电热间接排放 / 价值链其他间接排放 |
| 碳强度 | 单位产值或单位产品对应的碳排放，例如 tCO₂e/万元产值 |

## 硬件不可怕：只回答三个问题

很多开发者卡在硬件，是因为把它当成了一门新学科。其实从软件视角看，硬件链路只需要回答三个问题：

<Steps>
  <Step title="读什么？">
    现场有哪些能源介质、哪些计量点、每个点要采哪些数据。答案落在**点位表**上，这是软件和硬件之间唯一的契约。
  </Step>
  <Step title="怎么读？">
    仪表输出的是 RS-485、4-20mA、脉冲还是以太网；用什么协议、什么地址、什么数据格式。答案落在**通信参数**上。
  </Step>
  <Step title="怎么传？">
    仪表到网关、网关到平台分别走什么网络；断网了怎么办、时间怎么同步。答案落在**网络与边缘策略**上。
  </Step>
</Steps>

把这三个问题回答清楚，硬件就从“黑盒”变成了“一张有地址和格式的数据表”。[硬件详解](/nengtan/hardware/)会按这个顺序展开。

## 建议的学习路线

<Steps>
  <Step title="先读总体设计，确定边界">
    不要一上来就选技术。先明确：管哪些能源、覆盖哪些组织、碳核算做到范围几、要不要对接现有 PLC/MES。边界变了，后面的选型和表结构都会变。
  </Step>
  <Step title="再定技术栈，锁定版本">
    按团队熟悉度和交付周期选一条技术路线，把版本号写进 `pom.xml` 和 `package.json`。避免“边做边换框架”。
  </Step>
  <Step title="然后啃硬件，产出点位表">
    哪怕硬件是外包的，点位表也必须由你主导。它是采集服务、数据库、报警规则和碳核算的共同输入。
  </Step>
  <Step title="最后做若依实现与部署">
    先用模拟器把采集链路跑通，再接真实仪表；先做一条能源介质的闭环，再复制到其他介质。
  </Step>
</Steps>

<Aside type="tip" title="一条经验">
  能碳项目最容易返工的地方不是代码，而是**计量点规划**和**点位表**。这两样一旦现场施工完成，改动成本极高。宁可前期多花一周核对，也不要上线后才发现总表和分表对不上。
</Aside>

## 安全声明

<Aside type="danger" title="强电作业必须由持证电工完成">
  电表、互感器、配电柜的安装和接线涉及 220V/380V 强电，操作不当会危及生命。本教程中的接线内容用于帮助你**理解原理和验收施工**，不替代电气施工规范，也不构成让你自行带电作业的建议。所有强电作业必须停电、验电、挂牌，并由持证电工执行。
</Aside>

## 教程约定

- 代码以 **RuoYi-Vue 前后端分离版 + Vue 3** 为主线；微服务版和 RuoYi-Vue-Plus 在技术栈章节单独说明。
- 价格均为 **2026 年国内常见区间的估算**，仅用于做预算量级，实际以询价为准。
- 排放因子是**示例值**，正式核算必须使用生态环境部、行业指南或客户认可的最新因子，并在系统里做成可配置、可追溯的因子库。
- 所有 SQL、Java、YAML 代码都是**可改造的骨架**，不是复制即可上生产的完整产品。
