CFNext：最新 Cloudflare Workers 免费节点项目，在 Cloudflare Workers / Pages 的代理订阅管理面板中部署，单文件同时实现 VLESS / Trojan / XHTTP 多协议代理与图形化配置：/UUID（或自定义路径）进入面板，/sub输出订阅；内置节点优选器、节点数量控制、轮询下发、ECH 加密、落地与出站代理及地区 / 运营商 / IP 版本多维筛选，部署即用，绑定 KV 后改完成即生效。

**CFNext 项目地址**：[https://github.com/netrair/netra-panel](https://github.com/PAICNI/CFNext)

**CFNext 主要功能**

- 运行于 Cloudflare Workers — 无需 VPS、无需 Docker，省去维护和重启服务器的繁琐。
- 多协议支持：VLESS / Trojan / XHTTP 三协议独立开关，可同时启用；Trojan 密码留空默认使用 UUID。
- 订阅模式：关闭（默认）/ 自定义订阅（支持汇聚）/ 随机优选模式（官方接口）三种模式切换
- 节点数量控制：下拉开关 + 数量输入，开启后精确控制下发节点总数（1-1000）
- 轮询机制：默认开启：Clash 上限 300 / V2rayN 上限 800，更新订阅覆盖旧节点；关闭后忽略限制一次下发全部
- 优选器：内置微测网 IPv4/IPv6、优选 IP 列表、HostMonit 优选、微测优选域名 + 自定义数据源 URL；在线 TCP 测速后「加入优选」随订阅下发
- 自定义订阅：内置 6 条在线源（bestcf 地区源，可增删），支持域名 / 优选 API / IP 逐行汇聚；可切换「仅自定义节点」——关闭后只下发输入框内内容
- 地区与筛选：地区选择（全部 / 香港 / 台湾 / 美国 / 新加坡 / 日本 / 韩国 / 德国）+ IP 版本（IPv4 / IPv6）+ 运营商（移动 / 联通 / 电信）组合筛选
- 落地与出站：反代 / 落地 IP（留空使用内置 VLESS 中继 + 地区反代兜底；填写后启用透明代理）+ 出站代理（SOCKS5 / HTTP，user:pass@host:port）+ 出站模式选择
- ECH 加密：自定义 ECH 域名 / ECH DNS（DoH），开启后自动进入仅 TLS 节点模式
- 多客户端：Clash / Sing-box / Surge / Loon / Quantumult X / V2ray / Shadowrocket / Nekoray / Stash，按 UA 自动识别（URL 追加 ?format= 可强制指定）
- ...

## 部署教程

### 把域名托管到 Cloudflare

虽然 Cloudflare 提供了默认域名，但由于众所周知的原因无法在大陆直连。建议绑定自己的域名并开启 CDN。你可以使用[免费域名](https://www.zoio.net/2026/02/free-indevs-in-domain.html)，并参考教程将[域名托管到 Cloudflare](https://www.zoio.net/2026/01/cloudflare.html)。

---

### 创建 Workers KV

登录 Cloudflare，在左侧菜单栏选择「存储和数据库」-「Workers KV」，点击右上角的「Create Instance」创建 KV 空间。

![创建 Workers KV](/images/protocols/netra-panel-2-1a2c496a39.jpg)

在命名空间名称中填写自定义的 KV 空间名，点击创建。

![自定义 Workers KV 空间名](/images/protocols/netra-panel-3-cf5dd02852.jpg)

---

### 创建 Workers

登录 Cloudflare，在「计算和 AI」菜单选择「Workers 和 Pages」，点击右上角的「创建应用程序」。

![创建 Workers](/images/protocols/netra-panel-4-c89d4322d4.jpg)

点击选择「从 Hello World! 开始」。

![创建 Workers](/images/protocols/netra-panel-5-2181d6dc03.jpg)

Worker 名称可随便输入（作为默认域名前缀），然后点击「部署」。

![部署 Workers](/images/protocols/netra-panel-6-e898b37821.jpg)

---

### 部署 CFNext 代码

打开 CFNext 的项目代码页面：[https://github.com/PAICNI/CFNext/blob/CFNext 混淆版.js](https://github.com/PAICNI/CFNext/blob/929ceeb9a879a121c3c95c430f72686746794079/CFNext%20%E6%B7%B7%E6%B7%86%E7%89%88.js) ，点击右上角的「复制」图标，复制全部项目代码。

![复制 Netra Panel 项目代码](/images/protocols/cfnext-1-c9ad3b7b2a.jpg)

回到 Cloudflare Workers 管理后台，点击右上角的「编辑代码」。

![Cloudflare Workers 编辑代码](/images/protocols/netra-panel-8-98b4c294ed.jpg)

**清空**原有代码，将复制的 CFNext 项目代码粘贴到代码区域，然后点击右上角的「部署」。

![Netra Panel 项目代码部署](/images/protocols/cfnext-2-e45ba52cb2.jpg)

---

### 添加变量

在 Worker 的「设置」 - 「添加变量」。

![添加变量](/images/protocols/cfnext-3-8d8e672f6b.jpg)

添加环境变量

![添加环境变量](/images/protocols/cfnext-4-017275abf5.jpg)

- 秘钥：填写大写字母 `U`
- 值：你的 UUID （[UUID 在线生成](https://www.zoio.net/p/uuid.html)）

---

### 绑定 KV 空间

在 Worker 的「设置」 - 「变量和绑定」标签页中，找到 KV 命名空间绑定并点击「添加绑定」。

![添加绑定](/images/protocols/netra-panel-10-624667957b.jpg)

选择「KV 命名空间」，点击「添加绑定」：

![绑定 KV 命名空间](/images/protocols/netra-panel-11-f42c43c8eb.jpg)

- 变量名称：填写大写字母 `K`
- KV 命名空间：选择刚刚创建好的 Workers KV

![绑定 KV 命名空间](/images/protocols/cfnext-10-e12b45a85d.jpg)

---

### 添加自定义域

Cloudflare 官方分配给 Workers 的默认二级域名（以 `*.workers.dev` 结尾）在中国大陆已被全面阻断,下发的节点 SNI 取自访问域名，会导致客户端真连接延时全部 -1。为了正常使用，建议绑定一个自定义域名。

在 Worker 设置中选择「域和路由」标签页，点击「添加自定义域」。

![设置自定义域](/images/protocols/netra-panel-13-3eecba489c.jpg)

输入你托管在 Cloudflare 上的子域名，然后点击「添加域」。

![设置自定义域](/images/protocols/cfnext-5-981c5cfd5b.jpg)

---

### CFNext 面板配置

打开你的 Worker 访问地址（或绑定的自定义域名），在网址末尾加上 `/你的 UUID`（例如 `https://your-domain.com/b6ac4304-8f5a-407b-bcbf-5e18ddb0abb1`）以打开管理后台。

![CFNext 面板](/images/protocols/cfnext-6-46667bb34b.jpg)

在「订阅地址」订阅链接。

![CFNext 订阅链接](/images/protocols/cfnext-7-520a9e76e5.jpg)

其他详细配置请根据自己需求自行研究。
