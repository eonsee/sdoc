解决这个痛点的核心方案，就是让自建的 VPS 节点连接一个住宅代理（Residential Proxy），形成所谓的“链式代理”（即：**国内用户 → 3x-ui 节点 → 海外住宅 IP**）。这样既能享受优质线路带来的极速与稳定，又能解锁绝大部分海外服务的纯净住宅 IP。

---

## 核心原理：什么是链式代理？

直接连接海外住宅代理通常会非常卡顿或连接失败，因此标准的链路通常包含两个部分：

1. **中转 VPS（前置节点）**：推荐使用接通顶级优化线路（如搬瓦工 CN2 GIA 等）的 VPS。由于绝大部分住宅 IP 本身没有做中国大陆方向的线路优化，通过高端中转 VPS 可以大幅降低丢包率，网速优化非常显著。
2. **住宅代理（落地节点）**：分为两类：
   - **端口注册 IP**：商家提供 IP 地址、端口、账号和密码（支持 SOCKS5 / HTTP 协议）。它不是一台完整的 VPS，不能通过 SSH 登录，通常属于“伪住宅”（纯净度中规中矩，但价格便宜、性价比高）。
   - **住宅 VPS**：功能完备的 VPS，但自带的是真实海外家庭宽带运营商的住宅 IP（如美国 AT&T 宽带），可自由通过 3x-ui 搭建节点，纯净度极高，但价格昂贵。

今天我们使用 **中转 VPS + 端口住宅 IP** 方案，大众最常用。价格和性能最平衡，适合个人自用及日常海外业务。

需要提前说明的是：链式代理本质是两跳网络（用户 → 中转 → 住宅 IP），即便中转线路再优质，也会比单纯连接中转节点增加一定延迟——这是链式方案本身的固有取舍，而非配置错误，请提前调整预期。

## 中转 VPS + 端口住宅 IP 搭建步骤

### 1. 3x-ui 面板搭建

推荐中转 VPS ，部署 3x-ui 面板并完成 REALITY 节点搭建：具体安装与 Reality 节点搭建步骤，可参考本系列 [第一篇：面板安装教程](/protocols/3x-ui-guide-1/) 与 [第二篇：VLESS + Reality 节点配置教程](/protocols/3x-ui-guide-2/)，此处不再重复

### 2. 获取静态住宅 IP

购买端口住宅代理：购买支持较大带宽的住宅代理（例如 Proxy Sealer 的 ISP 套餐），获取其提供的 IP 地址、端口、用户名及密码。注意区分两种计费模式——按流量（GB）计费与不限流量的 ISP 套餐，长期高频使用建议优先选择后者，避免流量超额产生额外费用。

- 也可尝试：[免费白嫖 住宅 IP 代理 通过链式代理配置家庭宽带 IP 落地](https://www.zoio.net/2026/02/proxy-chain-residential.html)，如有长期需求，还是建议购买一个稳定的家宽IP。
